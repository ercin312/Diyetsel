DIYETSEL CARTOON UI — ASSET & STYLE BRIEF

Use the supplied assets as visual references for a Turkish nutrition / wellness mobile app.
Do NOT recreate the screenshot as one flat image. Build the interface as real, responsive mobile UI components.

VISUAL LANGUAGE
- Friendly hand-drawn cartoon / children's-book illustration style, but still premium and suitable for adults.
- Warm cream/off-white background.
- Rounded cards with thin, soft outlines and very subtle shadows.
- Main green: #6DBF67
- Warm yellow/orange: #FFB347
- Coral/orange: #FF7A45
- Sky blue: #6EC5FF
- Purple: #A78BFA
- Cream: #FFF6E9
- Use generous whitespace and large rounded touch targets.
- Illustrations should have expressive faces, organic imperfect outlines, and a cohesive hand-drawn feel.
- Avoid generic emoji-style icons; use the supplied illustrated assets wherever appropriate.
